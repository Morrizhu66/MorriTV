# 视频 Prompt 灵感库设计

## 目标

为已完成的视频任务提供手动收藏能力。每条灵感持久保存视频、完整 Prompt、生成参数及有序参考图，并能一键恢复到生成区。输入区参考素材支持拖动排序；收藏夹内任意图片支持追加到输入区。

## 交互

- 成片区的已完成视频显示“存入灵感库”，重复收藏同一任务时返回已有条目。
- 成片区旁新增“灵感库”页签。卡片以视频为主视觉，显示 Prompt、参考图序列、“一键复刻”和“删除灵感”。
- 一键复刻恢复视频模式、模型、Prompt、画幅、时长、清晰度及参考素材顺序，不自动提交。
- 输入区参考素材显示序号和拖拽手柄，可任意排序且不设置前端数量上限。
- 收藏夹中的图片显示“填入输入框”，追加到现有素材末尾并滚动到生成区；视频素材不显示该按钮。

## 持久化与安全

使用 `inspiration-library.json` 保存元数据，使用 `inspirations/<id>/` 保存视频及参考图副本，因此原任务或收藏夹素材移动、删除后灵感仍完整可用。删除灵感进入现有 `trash/`，不影响原任务和原素材。模型接口本身的素材数量限制仍在提交时校验。
